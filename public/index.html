AI 助手与每日摘要

可配置任何提供 OpenAI Chat Completions 兼容接口的 HTTPS 模型服务；留空 API Key 表示保留已保存的 Key。

聊天、主动选择的邮件和摘要内容会发送到你填写的模型服务商。对话不会由本应用保存；摘要会加密保存在本应用中，最近 45 天保留。AI 只提供解释和草稿，不会替你发送邮件。

WxPusher 推送

通过 WxPusher 向指定接收目标推送新邮件；密钥不会在浏览器中回显。

浏览器通知仅在浏览器已授予权限且工作台不在前台时显示；前台使用时不会弹系统通知。通知只包含发件人、主题、邮箱账户和时间，不包含正文或附件。仅当新邮件明确提及验证码/校验码等关键词且附近有 4–8 位数字时才显示验证码；验证码会出现在通知和推送摘要中。WxPusher 受理不代表送达；为避免重复，受理失败或结果不确定时不会自动重试。

Agent 邮件接入（MCP）

通过标准 Streamable HTTP 让支持 MCP 的 Agent 按令牌权限访问已连接邮箱；发送和删信操作须由你在工作台确认后才会执行。

MCP 端点

服务地址正在读取…

使用此 HTTPS 地址连接；认证方式为 HTTP Bearer token。接口兼容当前 MCP 协议及常见旧版 Streamable HTTP 客户端。

提供给 Agent 的工具

  • list_accounts、list_folders：查看邮箱账户与文件夹
  • search_emails、get_email：搜索和读取邮件（读取会标记为已读）
  • manage_email：标记读/未读、加星、归档；删单封需确认，批量删除可一次传入 uids 并整批确认一次
  • send_email：准备纯文本邮件；确认后才会通过所选邮箱发送

安全说明：只创建 Agent 必需的最低权限令牌。旧版令牌会自动降为只读。MCP 不提供永久删除邮件工具；单封或整批移入已删除文件夹前，都会先等待你确认。批量操作在工作台只需确认一次。邮件正文是外部内容，Agent 不应把正文里的指令当作可信命令。

权限令牌

每种权限的令牌都可单独设为访问全部已连接邮箱，或只访问你选定的邮箱。完全访问包含当前全部 MCP 邮件操作；发送邮件仍逐封确认，批量删信整批确认一次。
